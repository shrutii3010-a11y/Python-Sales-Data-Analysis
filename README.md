Python Sales Data Analysis

Project Overview

This project focuses on analyzing sales data using Python to identify sales trends, category performance, regional performance, and top-selling products.

Dataset

Sample Superstore Sales Dataset.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning & Processing

- Removed duplicate records.
- Handled missing values.
- Converted date columns into datetime format.
- Extracted month and year from Order Date.

Key Insights

- Technology is the highest sales-generating category.
- West is the highest sales region.
- November has the highest sales.

Conclusion

This project helped me gain practical experience in Python, data cleaning, data processing, exploratory data analysis, and data visualization.
